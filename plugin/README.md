# evo.player

Quickshell panel for the music library. The bar icon is the volume control. Left click opens now playing and recent scrobbles. While Brave is playing, that title is shown beside the icon.

Hyprdots loads this plugin from `vendor/evoplayer`. Toggle the panel with `evo ipc shell toggle evo.panels.player`.

Network: none in the bar plugin (the player process may network on its own).
